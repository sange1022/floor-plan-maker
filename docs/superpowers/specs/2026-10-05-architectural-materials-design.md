# 平面图制作：建筑材质填充与界面整理

## 目标与范围

将现有纯色油漆桶扩展为建筑平面图材质填充工具，保留现有 PDF 导入、围合识别、配色、线稿置顶/置底、独立阴影、背景、旋转、裁切和保存导出。用户已同意此前提出的八种纹理和左右界面整理方向。本文件是实现前待用户审阅的设计，不代表功能已经完成。

成功标准：选择材质后点击闭合区域即可填充；材质可独立调整和撤回；纹理不影响识别；同色不同材质互不联动；旧项目可继续打开；材质在画布、保存和导出中一致。

## 方案选择

1. 在现有颜色图层上直接叠纹理：改动较少，但无法区分同色不同材质，不采用。
2. 区域独立记录、按材质归组，使用程序化无缝图案：推荐；便于编辑、高清输出，不依赖远程图片。
3. 引入完整矢量/CAD编辑器：超出当前填色用途，本次不采用。

## 材质与交互

第一版内置：错缝砖、铺地砖、木地板、人字拼、方形石材、水磨石、混凝土、45°剖面线。所有预设使用可重复的本地图案；砖类明确标注用途，避免把立面照片当成墙体剖面规范。

用户选择纯色或纹理后，油漆桶点击现有闭合区域。已填区域可以替换材质，同色也允许替换；开放区域和点击线条仍给出原有明确提示。

属性提供纹理尺寸（图像像素，首版不宣称真实建筑尺寸）、角度、底色、纹理色、纹理透明度。图案以画布坐标为锚，避免相邻区域随机接缝；同材质保持连贯，允许通过“仅此区域”创建独立材质实例改变方向。

编辑范围：默认“仅此区域”，可切换“同材质全部区域”。移除纹理保留底色；删除填充清空对应区域或材质组，操作必须可撤回。纹理透明度与整个材质图层透明度分开。

## 状态与渲染

将区域分配与材质定义分离：像素归属平面记录材质实例 ID，材质记录包含名称、预设类型、底色、纹理色、尺寸、角度、纹理透明度，以及图层可见性、整体透明度、阴影。区域选择基于原始线稿识别掩码，不从渲染结果取边界。

原始围合遍历仍是几何依据；纹理作为材质渲染结果裁在该材质的区域掩码中，不能写入线稿识别掩码。纯色使用同一材质接口，保持同颜色默认归组的现有体验。同颜色不同纹理须拥有不同实例 ID。

新增独立材质预设/图案生成模块、材质状态与兼容转换模块、材质选择组件和属性组件。EditorCanvas保留围合遍历与画布管理职责，共享组合渲染函数供预览和导出使用。图案按参数缓存；悬停仍使用独立画布，不重复计算阴影。

线稿上层顺序：背景 → 阴影 → 材质填充 → 线稿；线稿下层顺序：背景 → 线稿 → 阴影 → 材质填充。图案只替换填充渲染，不改变线稿层级语义。

## 历史、几何变换与项目兼容

历史快照必须同时保存填充归属、材质参数、可见性、透明度与阴影设置，撤回/重做不能只恢复像素。限制快照数量延续现有按画布大小的策略。

旋转和裁切同步变换材质归属平面；整张图旋转时纹理方向随作品旋转。重识别保留已有材质归属，不把纹理当成新边界。

项目格式增加版本号和材质字段。旧项目由原填充 PNG 和按颜色的设置转换为纯色材质实例，不丢失底色、隐藏、透明度或阴影。新项目保存图案参数与归属数据，不依赖在线资源。无法识别的材质类型回退到底色并提示用户。

普通/透明PNG导出均使用与预览相同的材质组合过程；1x/2x导出图案密度必须一致，2x不是把纹理变密。

## 界面

保留苹果系统字体与左右工作区，不整体重设计。

- 左侧窄工具栏保留现有工具与配色入口，增加材质入口。弹出的材质库分“纯色/纹理”，纹理按分类下拉选择，以紧凑缩略图展示，不永久挤占画布。
- 中央优先保留最大预览面积，上方现有撤回、重做、旋转、适应画布、200%居中不改变。
- 右侧切换“属性/图层”。属性显示当前选中区域或材质；图层显示缩略图、名称、区域数、可见性、透明度和删除入口，保留线稿层级控件。
- 背景、画布、识别、历史、文档、导出通过上方设置入口/紧凑面板访问；保持全部功能可到达，避免多个长区块同时展开。窄屏使用可关闭面板，不产生页面横向溢出。

不选中区域时，属性面板明确显示“下一次填充”的材质，避免参数修改意外影响已有作品。

## 验证

先增加失败测试，再实现：八种图案输出、相同底色不同材质隔离、局部与整组修改、移除纹理保留底色、隐藏/透明度、开放区域拒绝填充、替换同色材质。

浏览器验证真实PDF与透明PNG：油漆桶、悬停、撤回/重做、四次90°旋转、裁切、重识别、项目保存再打开、旧格式加载、普通/透明1x/2x导出；确认纹理不越界且预览与导出一致。

运行构建与自动测试；桌面和窄屏检查功能入口、画布面积、无页面溢出、无浏览器报错。先提供本地可测试版本；本次不自动推送部署。

## 暂不包含

自定义图片材质上传、毫米比例标定、完整CAD绘制、多人协作、真实三维渲染。先保证八种纹理与原有填色稳定，再逐项扩展。
